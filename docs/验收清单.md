### 打开和权限

- [x] **A1** 未插设备时打开应用。预览区是「等待 USB 摄像头」，左侧栏和底部快门都在，应用不崩溃。模拟器上看到这三项，进程未退出。
- [ ] **A2**（CON-02）第一次插上设备，系统弹出 USB 权限。点拒绝后应用不崩溃，仍停在等待或可重试。阻塞：模拟器没有 USB 设备，系统 USB 权限框没有出现。
- [ ] **A3**（CON-02）再次请求权限并允许。十秒内出预览，右上角帧率数字会变化。阻塞：没有 UVC。帧率停在 0 FPS。
- [x] **A4** 相机、麦克风权限被拒绝时，界面说明需要权限，并提供重试。允许后能进入预览。拒绝相机和麦克风后，界面是「需要相机、麦克风和相册权限」和「重试」，没有崩溃。点重试并允许后进入等待页。没有设备，所以没有实际画面。相册权限在模拟器上是单独的「Allow all」。

### 设备和预览

- [ ] **A6**（CON-01）接上两台 UVC 时，点另一台后画面切换到新设备。没有第二台则标阻塞。阻塞：没有第二台，也没有第一台。
- [ ] **A7**（CON-03）预览过程中拔出设备。画面停止，界面回到等待，不崩溃。阻塞：没有正在预览的设备。
- [ ] **A8**（CON-03）拔出时如果正在录像，拔出后文件停止增长，已写入的部分尽量可播放。若文件损坏，记失败并保留文件。阻塞：没有录像。

### 左侧栏

### 拍照、录像、录音

- [ ] **A12**（CAP-01）模式为拍照，按快门。相册 `DCIM/Camera` 出现一张新的 JPEG，能打开，不是半张或 0 字节。阻塞：没有 UVC。无设备时按快门没有生成文件，也没有提示。
- [ ] **A13**（CAP-02）模式为录像，按快门开始。计时增加，快门变为停止。再按一次停止。相册或文件管理里的 MP4 能播放，有画面。阻塞：没有 UVC。
- [ ] **A14**（CAP-02）设置里分段选 1 分钟，录像超过一分钟。得到至少两段都能播放的文件。测完改回不分段。时间不够则标阻塞，不要为了这一条录满一分钟以外的更长分段。阻塞：没有录像。设置里能看到「1 分钟」。
- [ ] **A15**（CAP-03）模式为录音，开始再停止。得到可播放的 MP3。这不是录像按钮。阻塞：没有 UVC。录音按钮在，没有开始录音。
- [ ] **A16**（CAP-04）录像进行中，拍照 / 录像 / 录音不能切换。分辨率、MJPEG/YUYV、分段、音源不能改。停止后这些又能改。阻塞：没有进入录像。
- [ ] **A17**（CAP-04）录音进行中同样不能改模式。停止后模式恢复可选。阻塞：没有进入录音。

### 视频格式、方向、分辨率

- [ ] **A18** 在「视频」里从 MJPEG 改到 YUYV。预览重新打开并出画。再改回 MJPEG，仍然出画。阻塞：没有预览。面板上 MJPEG 当前选中，YUYV 可选，没有出画。
- [ ] **A19**（IMG-02）依次选 90°、180°、270°、0°，以及上下翻转、左右翻转。预览马上跟着变。阻塞：没有预览。六个选项都在，当前是 0°。

### 画面

- [ ] **A23**（IMG-01）拖动亮度，预览明暗有变化。点恢复默认后，画面回到设备默认观感，滑杆不再停在刚才的极端值。阻塞：没有预览，也没有亮度滑杆。
- [ ] **A24**（IMG-01）设备支持时能看到自动对焦、自动白平衡，开关能拨动且不崩溃。设备不支持时这两项不出现。阻塞：没有设备。这两项没有出现。

## C. 明确不测

下面这些不在当前和下一版本里。看到没有入口是正常的，不要开缺陷。

- Flutter 里的多路网格。网格仍以 `reference/` 的 Android 界面为准，本清单不测那套界面。
